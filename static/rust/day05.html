1. String 与 &str

字符串字面量：

#![allow(unused)]
fn main() {
let s = "rust";
}

这里 s 的类型是：

#![allow(unused)]
fn main() {
&str
}

它是一个只读字符串 slice，不拥有字符串数据，不能修改。

拥有型字符串：

#![allow(unused)]
fn main() {
let mut s = String::from("rust");
s.push('!');
s.push_str(" language");
}

这里 s 的类型是：

#![allow(unused)]
fn main() {
String
}

String::from("rust") 可以理解成：

从 &str 创建一个拥有所有权、可增长、可修改的 String。

等价常见写法还有：

#![allow(unused)]
fn main() {
let s = "rust".to_string();
}

2. vec!["rust", "ai"] 和 vec![String::from(...)]

#![allow(unused)]
fn main() {
let tags = vec!["rust", "ai", "infra"];
}

类型是：

#![allow(unused)]
fn main() {
Vec<&str>
}

它只适合只读场景。

如果要修改字符串内容，需要：

#![allow(unused)]
fn main() {
let mut tags = vec![
    String::from("rust"),
    String::from("ai"),
    String::from("infra"),
];

for tag in &mut tags {
    tag.push('#');
}
}

此时类型是：

#![allow(unused)]
fn main() {
Vec<String>
}

可以拥有、修改、移动字符串。

3. String 常用方法

完整示例：

fn main() {
    let mut name = String::from("rust");

    name.push('!');
    name.push_str(" language");

    println!("name = {}", name);
    println!("contains rust? {}", name.contains("rust"));
    println!("replace = {}", name.replace("rust", "Rust"));
    println!("original after replace = {}", name);
}

要点：

方法作用
push(char)追加一个字符
push_str(&str)追加一段字符串
contains(&str)判断是否包含子串
replace(old, new)返回替换后的新 String，不修改原字符串

如果要保存替换结果，需要赋值：

#![allow(unused)]
fn main() {
name = name.replace("rust", "Rust");
}

4. split_whitespace()

fn main() {
    let text = "hello rust iterator";

    for word in text.split_whitespace() {
        println!("word = {:?}", word);
    }
}

split_whitespace() 返回 iterator，每个元素是：

#![allow(unused)]
fn main() {
&str
}

它没有复制新字符串，只是返回原字符串中的一段段借用。

5. Vec<T> 常用方法

fn main() {
    let mut nums = vec![10, 20, 30];

    nums.push(40);
    nums.push(50);

    println!("nums = {:?}", nums);
    println!("len = {}", nums.len());
    println!("contains 30? {}", nums.contains(&30));

    let last = nums.pop();
    println!("last = {:?}", last);
}

常用方法：

方法作用
push(value)追加元素
pop()弹出最后一个元素，返回 Option<T>
len()返回长度
contains(&value)判断是否包含某值
insert(index, value)在指定位置插入
remove(index)删除指定位置元素并返回

contains 使用 &30，因为它只是借用一个值来比较，不拿走所有权。

6. pop() 返回 Option<T>

fn main() {
    let mut nums = vec![10, 20];

    println!("{:?}", nums.pop());
    println!("{:?}", nums.pop());
    println!("{:?}", nums.pop());
}

输出：

Some(20)
Some(10)
None

原因：

Vec 有元素时：pop() 返回 Some(value)
Vec 为空时：pop() 返回 None

这和 Day 4 的 Option<T> 直接连起来。

7. vec[index] vs vec.get(index)

直接索引：

#![allow(unused)]
fn main() {
let nums = vec![10, 20, 30];
println!("{}", nums[1]);
}

如果越界，会运行时 panic：

println!("{}", nums[10]);

安全访问：

#![allow(unused)]
fn main() {
fn print_at(nums: &[i32], index: usize) {
    match nums.get(index) {
        Some(value) => println!("nums[{}] = {}", index, value),
        None => println!("index {} is out of bounds", index),
    }
}
}

get() 返回：

#![allow(unused)]
fn main() {
Option<&T>
}

也就是：

Some(&value)  找到了
None          越界

8. .iter() / .iter_mut() / .into_iter()

这三个方法是 Day 5 的核心。

方法产生什么是否能修改元素循环后原 Vec 还能用吗
.iter()&T不能能
.iter_mut()&mut T能能
.into_iter()T拿走所有权不能

例如：

#![allow(unused)]
fn main() {
let names = vec![String::from("alice"), String::from("bob")];

for name in names.iter() {
    println!("borrowed name = {}", name);
}

println!("names still usable = {:?}", names);
}

iter() 是借用遍历。

#![allow(unused)]
fn main() {
let mut words = vec![String::from("rust"), String::from("iterator")];

for word in words.iter_mut() {
    word.push('!');
}
}

iter_mut() 是可变借用遍历。

#![allow(unused)]
fn main() {
let animals = vec![String::from("cat"), String::from("dog")];

for animal in animals.into_iter() {
    println!("owned animal = {}", animal);
}
}

into_iter() 会把元素 move 出来，原 Vec 之后不能再用。

9. for 的三种简写

写法大致等价是否消耗原集合
for x in &vv.iter()不消耗
for x in &mut vv.iter_mut()不消耗，但可修改元素
for x in vv.into_iter()消耗

示例：

#![allow(unused)]
fn main() {
let nums = vec![1, 2, 3];
for x in &nums {
    println!("{}", x);
}
println!("{:?}", nums);
}
#![allow(unused)]
fn main() {
let mut scores = vec![80, 90, 100];
for score in &mut scores {
    *score += 5;
}
println!("{:?}", scores);
}
#![allow(unused)]
fn main() {
let names = vec![String::from("alice"), String::from("bob")];
for name in names {
    println!("{}", name);
}
// names 已经被 move，不能再用
}

10. closure：Rust 的 lambda

Rust 里的匿名函数叫 closure，写法是：

#![allow(unused)]
fn main() {
|x| x + 1
}

类似 Python：

lambda x: x + 1

也类似 C++：

[](int x) { return x + 1; }

示例：

fn main() {
    let add_one = |x| x + 1;
    println!("{}", add_one(10));
}

多个参数：

#![allow(unused)]
fn main() {
let add = |a, b| a + b;
}

显式类型：

#![allow(unused)]
fn main() {
let is_even = |x: i32| -> bool {
    x % 2 == 0
};
}

11. .map()

map 用来把每个元素变成另一个元素。

#![allow(unused)]
fn main() {
let nums = vec![1, 2, 3];

let doubled: Vec<i32> = nums
    .iter()
    .copied()
    .map(|x| x * 2)
    .collect();
}

流程：

1 -> 2
2 -> 4
3 -> 6

map 的特点：

输入几个元素，通常输出几个元素。
元素内容或类型可以改变。

12. .filter()

filter 用来保留满足条件的元素。

#![allow(unused)]
fn main() {
let nums = vec![1, 2, 3, 4];

let evens: Vec<i32> = nums
    .iter()
    .copied()
    .filter(|x| *x % 2 == 0)
    .collect();
}

filter 的 closure 返回 bool：

true  -> 保留
false -> 丢弃

为什么这里是 *x？

copied() 后 iterator item 是 i32。
filter 会把 item 的引用传给 closure。
所以 x 是 &i32，需要 *x 得到 i32。

13. .filter() 中的引用层级

如果写：

#![allow(unused)]
fn main() {
let evens: Vec<i32> = nums
    .iter()
    .filter(|x| **x % 2 == 0)
    .copied()
    .collect();
}

类型流动是：

nums.iter()                Item = &i32
filter 的参数 x             &&i32
filter 后保留的 Item 仍然是  &i32
copied()                   &i32 -> i32
collect()                  Vec<i32>

关键点：

filter 没有把 &&i32 变成 &i32。
filter 只是用 &&i32 判断是否保留元素。
保留下来的元素仍然是原 iterator 的 item，也就是 &i32。
copied() 才把 &i32 变成 i32。

初学阶段推荐先写：

#![allow(unused)]
fn main() {
let evens: Vec<i32> = nums
    .iter()
    .copied()
    .filter(|x| *x % 2 == 0)
    .collect();
}

更好理解。

14. .collect() 与 turbofish

collect() 把 iterator 收集成集合。

常见写法一：左边标注类型。

#![allow(unused)]
fn main() {
let squares: Vec<i32> = nums
    .iter()
    .copied()
    .map(|x| x * x)
    .collect();
}

常见写法二：右边 turbofish。

#![allow(unused)]
fn main() {
let squares = nums
    .iter()
    .copied()
    .map(|x| x * x)
    .collect::<Vec<i32>>();
}

::<Vec<i32>> 就是在告诉编译器：

请收集成 Vec<i32>。

15. .filter_map()

filter_map() 可以理解成：

转换 + 丢弃失败项

示例：

fn main() {
    let text = "10 20 abc 30 -5 xx";

    let numbers: Vec<i32> = text
        .split_whitespace()
        .filter_map(|word| word.parse::<i32>().ok())
        .collect();

    println!("numbers = {:?}", numbers);
}

流程：

"10"  -> Ok(10)  -> Some(10)  -> 保留
"20"  -> Ok(20)  -> Some(20)  -> 保留
"abc" -> Err     -> None      -> 丢弃
"30"  -> Ok(30)  -> Some(30)  -> 保留
"-5"  -> Ok(-5)  -> Some(-5)  -> 保留
"xx"  -> Err     -> None      -> 丢弃

结果：

[10, 20, 30, -5]

手写循环版本：

#![allow(unused)]
fn main() {
let text = "10 20 bad 30 xx -5";
let mut numbers = Vec::new();

for word in text.split_whitespace() {
    match word.parse::<i32>() {
        Ok(value) => numbers.push(value),
        Err(_) => println!("skip invalid word = {:?}", word),
    }
}
}

初学阶段建议：先会手写循环，再写 iterator 链。

16. Vec<&str> 与 Vec<String>

#![allow(unused)]
fn main() {
let line = "Rust makes Rust safer";

let borrowed_words: Vec<&str> = line.split_whitespace().collect();
}

这里没有复制字符串，只是借用 line 中的片段。

#![allow(unused)]
fn main() {
let owned_words: Vec<String> = line
    .split_whitespace()
    .map(|word| word.to_string())
    .collect();
}

这里每个单词都被复制成新的 String。

判断原则：

类型含义适合场景
Vec<&str>借用原字符串片段临时分析、只读、不脱离原字符串
Vec<String>拥有字符串要保存、返回、修改、脱离原字符串

17. .copied() vs .cloned()

#![allow(unused)]
fn main() {
let nums = vec![1, 2, 3];
let nums_copy: Vec<i32> = nums.iter().copied().collect();
}

copied() 用于 Copy 类型，例如：

i32, bool, char, f64

#![allow(unused)]
fn main() {
let names = vec![String::from("alice"), String::from("bob")];
let names_clone: Vec<String> = names.iter().cloned().collect();
}

cloned() 用于 Clone 类型，例如 String。它可能分配新内存，有成本。

方法用于什么例子成本
.copied()T: Copyi32, bool, char低
.cloned()T: CloneString, Vec<T>可能高

18. retain() 原地筛选

#![allow(unused)]
fn main() {
let mut scores = vec![95, 40, 82, 59, 100, 60];

scores.retain(|score| *score >= 60);

println!("{:?}", scores);
}

输出：

[95, 82, 100, 60]

retain() 会修改原 Vec。

对比：

filter().collect()  创建新 Vec
retain()            原地修改 Vec

19. sort() 与 dedup()

#![allow(unused)]
fn main() {
let mut words = vec![
    String::from("rust"),
    String::from("ai"),
    String::from("rust"),
    String::from("infra"),
    String::from("ai"),
];

words.sort();
words.dedup();

println!("{:?}", words);
}

sort() 原地排序。

dedup() 去掉相邻重复元素。

因此完整去重通常写：

#![allow(unused)]
fn main() {
words.sort();
words.dedup();
}

20. 字符串处理流水线

fn clean_word(word: &str) -> String {
    word.trim_matches(|c: char| !c.is_alphanumeric())
        .to_lowercase()
}

fn main() {
    let text = "Rust, rust! makes systems-programming safer.";

    let cleaned: Vec<String> = text
        .split_whitespace()
        .map(clean_word)
        .filter(|word| !word.is_empty())
        .collect();

    println!("cleaned = {:?}", cleaned);
}

map(clean_word) 等价于：

#![allow(unused)]
fn main() {
.map(|word| clean_word(word))
}

因为函数名也可以作为参数传给 map。

今日总结

Day 5 的核心地图：

概念关键点
String拥有型字符串，可修改
&str字符串 slice，只读借用
Vec<T>拥有一组同类型元素
&[T]借用一段连续元素
.iter()借用遍历，产生 &T
.iter_mut()可变借用遍历，产生 &mut T
.into_iter()消耗所有权遍历，产生 T
.map()转换每个元素
.filter()保留满足条件的元素
.filter_map()转换并丢弃失败项
.collect()收集 iterator 的结果
.copied()&T -> T，要求 T: Copy
.cloned()&T -> T，要求 T: Clone
.retain()原地筛选 Vec
.sort() / .dedup()排序和相邻去重

一句话总结：

Day 5 的主线是：Rust 用所有权区分借用遍历、可变遍历、消耗遍历；用 iterator 链表达数据处理流水线。
