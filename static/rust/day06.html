1. 定义 struct

Rust 用 struct 定义自定义数据类型。

#![allow(unused)]
fn main() {
struct User {
    name: String,
    age: u32,
    active: bool,
}
}

这表示定义了一个 User 类型，它有三个字段：

字段类型含义
nameString用户名，拥有字符串数据
ageu32年龄
activebool是否活跃

创建实例：

fn main() {
    let user1 = User {
        name: String::from("Alice"),
        age: 20,
        active: true,
    };

    println!("name = {}", user1.name);
    println!("age = {}", user1.age);
    println!("active = {}", user1.active);
}

struct User {
    name: String,
    age: u32,
    active: bool,
}

字段访问使用点号：

#![allow(unused)]
fn main() {
user1.name
user1.age
user1.active
}

2. 修改字段需要 mut

如果要修改字段，变量绑定本身必须是 mut：

fn main() {
    let mut user1 = User {
        name: String::from("Alice"),
        age: 20,
        active: true,
    };

    user1.age += 1;
    user1.active = false;

    println!("name = {}", user1.name);
    println!("age = {}", user1.age);
    println!("active = {}", user1.active);
}

struct User {
    name: String,
    age: u32,
    active: bool,
}

注意 Rust 不是给单个字段加 mut，而是：

#![allow(unused)]
fn main() {
let mut user1 = ...;
}

表示 user1 这个绑定可变，于是可以修改它的字段。

3. Debug 与 #[derive(Debug)]

单独打印字段可以用 {}：

#![allow(unused)]
fn main() {
println!("name = {}", user1.name);
}

但如果想直接打印整个结构体：

println!("user1 = {:?}", user1);

如果没有实现 Debug，编译器会报错：

`User` cannot be formatted using `{:?}` because it doesn't implement `Debug`
help: consider annotating `User` with `#[derive(Debug)]`

修复方式是在 struct 上方添加：

#![allow(unused)]
fn main() {
#[derive(Debug)]
}

完整示例：

#[derive(Debug)]
struct User {
    name: String,
    age: u32,
    active: bool,
}

fn main() {
    let mut user1 = User {
        name: String::from("Alice"),
        age: 20,
        active: true,
    };

    user1.age += 1;
    user1.active = false;

    println!("user1 = {:?}", user1);
}

输出类似：

user1 = User { name: "Alice", age: 21, active: false }

更漂亮的多行调试输出使用 {:#?}：

#![allow(unused)]
fn main() {
println!("user1 = {:#?}", user1);
}

输出类似：

user1 = User {
    name: "Alice",
    age: 21,
    active: false,
}

格式化规则：

写法含义
{}Display，面向用户的普通显示
{:?}Debug，面向开发者的调试显示
{:#?}pretty Debug，多行调试显示

4. impl：给类型定义方法

impl User 表示给 User 类型实现函数或方法。

#[derive(Debug)]
struct User {
    name: String,
    age: u32,
    active: bool,
}

impl User {
    fn greet(&self) {
        println!("Hello, my name is {}.", self.name);
    }

    fn is_adult(&self) -> bool {
        self.age >= 18
    }
}

fn main() {
    let user1 = User {
        name: String::from("Alice"),
        age: 21,
        active: true,
    };

    user1.greet();
    println!("is adult? {}", user1.is_adult());
    println!("user1 = {:#?}", user1);
}

这里：

#![allow(unused)]
fn main() {
fn greet(&self)
}

表示只读借用当前对象。

可以把：

#![allow(unused)]
fn main() {
user1.greet();
}

大致理解成：

User::greet(&user1);

is_adult 返回 bool：

#![allow(unused)]
fn main() {
fn is_adult(&self) -> bool {
    self.age >= 18
}
}

最后一行没有分号，因此是表达式，作为返回值。

如果写成：

fn is_adult(&self) -> bool {
    self.age >= 18;
}

会得到类似错误：

expected `bool`, found `()`

这复习了 Day 4 的规则：

没有分号的表达式产生值；
带分号的语句通常产生 ()。

5. &mut self：方法修改结构体

如果方法要修改结构体字段，就使用 &mut self：

#[derive(Debug)]
struct User {
    name: String,
    age: u32,
    active: bool,
}

impl User {
    fn greet(&self) {
        println!("Hello, my name is {}.", self.name);
    }

    fn is_adult(&self) -> bool {
        self.age >= 18
    }

    fn birthday(&mut self) {
        self.age += 1;
        println!("Happy birthday, {}!", self.name);
    }

    fn deactivate(&mut self) {
        self.active = false;
    }
}

fn main() {
    let mut user1 = User {
        name: String::from("Alice"),
        age: 17,
        active: true,
    };

    println!("before = {:#?}", user1);

    user1.greet();
    println!("is adult? {}", user1.is_adult());

    user1.birthday();
    println!("after birthday = {:#?}", user1);
    println!("is adult now? {}", user1.is_adult());

    user1.deactivate();
    println!("after deactivate = {:#?}", user1);
}

因为 birthday 和 deactivate 需要可变借用，变量必须声明为：

#![allow(unused)]
fn main() {
let mut user1 = ...;
}

如果写成：

let user1 = User { ... };
user1.birthday();

编译器会提示类似：

cannot borrow `user1` as mutable, as it is not declared as mutable
help: consider changing this to be mutable

6. self：消耗结构体

第三种方法接收者是：

#![allow(unused)]
fn main() {
self
}

它表示直接拿走整个对象的所有权。

#[derive(Debug)]
struct User {
    name: String,
    age: u32,
    active: bool,
}

impl User {
    fn greet(&self) {
        println!("Hello, my name is {}.", self.name);
    }

    fn birthday(&mut self) {
        self.age += 1;
    }

    fn into_name(self) -> String {
        self.name
    }
}

fn main() {
    let mut user1 = User {
        name: String::from("Alice"),
        age: 17,
        active: true,
    };

    user1.greet();

    user1.birthday();
    println!("after birthday = {:#?}", user1);

    let name = user1.into_name();
    println!("name = {}", name);

    // user1 已经被 into_name() 消耗，不能再使用
    // println!("user1 = {:#?}", user1);
}

into_name 的签名是：

#![allow(unused)]
fn main() {
fn into_name(self) -> String
}

调用：

#![allow(unused)]
fn main() {
let name = user1.into_name();
}

大致等价于：

let name = User::into_name(user1);

也就是 user1 被 move 进方法。方法内部把 self.name 移出并返回。

常见命名习惯：

into_xxx

通常表示：

消耗旧值，把它转换成新值。

例如标准库中的：

#![allow(unused)]
fn main() {
let s = String::from("abc");
let bytes = s.into_bytes();

// s 之后不能再用
}

7. &self、&mut self、self 对比

写法等价理解含义调用后原对象还能用吗
&selfself: &User只读借用能
&mut selfself: &mut User可变借用能
selfself: User拿走所有权通常不能

判断方法：

这个方法调用后，原对象还应该继续使用吗？

如果只是读取：用 &self。

如果要原地修改：用 &mut self。

如果要转换、拆包、终结对象生命周期：用 self。

8. 借用名字、克隆名字、消耗名字

同样是“得到名字”，可以有三种不同设计：

#[derive(Debug)]
struct User {
    name: String,
    age: u32,
    active: bool,
}

impl User {
    fn name(&self) -> &str {
        &self.name
    }

    fn cloned_name(&self) -> String {
        self.name.clone()
    }

    fn into_name(self) -> String {
        self.name
    }
}

fn main() {
    let user1 = User {
        name: String::from("Alice"),
        age: 21,
        active: true,
    };

    let borrowed_name = user1.name();
    println!("borrowed_name = {}", borrowed_name);
    println!("user1 after name() = {:#?}", user1);

    let copied_name = user1.cloned_name();
    println!("copied_name = {}", copied_name);
    println!("user1 after cloned_name() = {:#?}", user1);

    let owned_name = user1.into_name();
    println!("owned_name = {}", owned_name);

    // user1 已经被消耗
    // println!("user1 after into_name() = {:#?}", user1);
}

对比：

方法返回是否复制是否消耗 user1
name(&self)&str不复制不消耗
cloned_name(&self)String复制不消耗
into_name(self)String不额外复制消耗

9. 关联函数与构造函数模式

在 impl 中，如果函数没有 self 参数，它就是关联函数。

#[derive(Debug)]
struct User {
    name: String,
    age: u32,
    active: bool,
}

impl User {
    fn new(name: &str, age: u32) -> User {
        User {
            name: name.to_string(),
            age,
            active: true,
        }
    }
}

fn main() {
    let user1 = User::new("Alice", 21);
    println!("user1 = {:#?}", user1);
}

调用方式是：

#![allow(unused)]
fn main() {
User::new("Alice", 21)
}

不是：

user1.new(...)

Rust 没有固定的构造函数语法，但社区常用：

#![allow(unused)]
fn main() {
TypeName::new(...)
}

作为构造函数模式。

10. Self：当前类型

在：

#![allow(unused)]
fn main() {
impl User {
    ...
}
}

内部，Self 表示当前类型，也就是 User。

因此常见写法是：

#[derive(Debug)]
struct User {
    name: String,
    age: u32,
    active: bool,
}

impl User {
    fn new(name: &str, age: u32) -> Self {
        Self {
            name: name.to_string(),
            age,
            active: true,
        }
    }

    fn guest() -> Self {
        Self {
            name: String::from("guest"),
            age: 0,
            active: false,
        }
    }
}

fn main() {
    let user1 = User::new("Alice", 21);
    let guest = User::guest();

    println!("user1 = {:#?}", user1);
    println!("guest = {:#?}", guest);
}

这里：

#![allow(unused)]
fn main() {
fn new(...) -> Self
}

等价于：

#![allow(unused)]
fn main() {
fn new(...) -> User
}
#![allow(unused)]
fn main() {
Self { ... }
}

等价于：

#![allow(unused)]
fn main() {
User { ... }
}

11. 字段初始化简写

如果字段名和变量名相同，可以简写。

#![allow(unused)]
fn main() {
fn new(name: &str, age: u32) -> Self {
    Self {
        name: name.to_string(),
        age,
        active: true,
    }
}
}

其中：

#![allow(unused)]
fn main() {
age,
}

等价于：

#![allow(unused)]
fn main() {
age: age,
}

12. struct update syntax：..user1

Rust 可以基于旧结构体创建新结构体：

#[derive(Debug)]
struct User {
    name: String,
    age: u32,
    active: bool,
}

impl User {
    fn new(name: &str, age: u32) -> Self {
        Self {
            name: name.to_string(),
            age,
            active: true,
        }
    }
}

fn main() {
    let user1 = User::new("Alice", 21);

    let user2 = User {
        name: String::from("Bob"),
        ..user1
    };

    println!("user2 = {:#?}", user2);
}

这里：

#![allow(unused)]
fn main() {
..user1
}

表示剩余字段从 user1 补齐。

在上面的例子中，age: u32 和 active: bool 都是 Copy 类型，因此复制即可。

如果没有被覆盖的字段里包含 String，就会发生 move：

#[derive(Debug)]
struct User {
    name: String,
    email: String,
    age: u32,
    active: bool,
}

impl User {
    fn new(name: &str, email: &str, age: u32) -> Self {
        Self {
            name: name.to_string(),
            email: email.to_string(),
            age,
            active: true,
        }
    }
}

fn main() {
    let user1 = User::new("Alice", "alice@example.com", 21);

    let user2 = User {
        name: String::from("Bob"),
        ..user1
    };

    println!("user2 = {:#?}", user2);

    // user1.email 已经被 move 到 user2，user1 不能再整体使用
    println!("user1 = {:#?}", user1);
}

核心规则：

struct update syntax 会从旧对象补齐字段；
Copy 字段会复制；
非 Copy 字段会 move。

13. Builder 风格：消耗并返回 Self

self 的一个常见用途是 builder 模式。

#[derive(Debug)]
struct Config {
    batch_size: usize,
    learning_rate: f64,
    device: String,
}

impl Config {
    fn new() -> Self {
        Self {
            batch_size: 1,
            learning_rate: 0.01,
            device: String::from("cpu"),
        }
    }

    fn with_batch_size(mut self, batch_size: usize) -> Self {
        self.batch_size = batch_size;
        self
    }

    fn with_learning_rate(mut self, learning_rate: f64) -> Self {
        self.learning_rate = learning_rate;
        self
    }

    fn with_device(mut self, device: &str) -> Self {
        self.device = device.to_string();
        self
    }
}

fn main() {
    let config = Config::new()
        .with_batch_size(32)
        .with_learning_rate(0.001)
        .with_device("cuda");

    println!("config = {:#?}", config);
}

每个 with_xxx 都消耗旧的 Config，修改后返回新的 Config，因此可以链式调用。

14. 科学计算风格示例：Particle

下面的例子把今天的内容组合起来：

struct 表示状态
impl 表示状态上的操作
&self 读取状态
&mut self 更新状态
self 消耗并转换状态

#[derive(Debug)]
struct Particle {
    position: f64,
    velocity: f64,
    mass: f64,
}

impl Particle {
    fn new(position: f64, velocity: f64, mass: f64) -> Self {
        Self {
            position,
            velocity,
            mass,
        }
    }

    fn kinetic_energy(&self) -> f64 {
        0.5 * self.mass * self.velocity * self.velocity
    }

    fn momentum(&self) -> f64 {
        self.mass * self.velocity
    }

    fn is_moving(&self) -> bool {
        self.velocity != 0.0
    }

    fn apply_force(&mut self, force: f64, dt: f64) {
        let acceleration = force / self.mass;
        self.velocity += acceleration * dt;
    }

    fn step(&mut self, dt: f64) {
        self.position += self.velocity * dt;
    }

    fn stop(&mut self) {
        self.velocity = 0.0;
    }

    fn into_tuple(self) -> (f64, f64, f64) {
        (self.position, self.velocity, self.mass)
    }
}

fn main() {
    let mut p = Particle::new(0.0, 2.0, 1.5);

    println!("initial particle = {:#?}", p);
    println!("kinetic energy = {}", p.kinetic_energy());
    println!("momentum = {}", p.momentum());
    println!("is moving? {}", p.is_moving());

    p.apply_force(3.0, 0.1);
    p.step(0.1);

    println!("after update = {:#?}", p);
    println!("kinetic energy = {}", p.kinetic_energy());
    println!("momentum = {}", p.momentum());

    p.stop();
    println!("after stop = {:#?}", p);
    println!("is moving? {}", p.is_moving());

    let raw = p.into_tuple();
    println!("raw tuple = {:?}", raw);

    // p 已经被 into_tuple() 消耗，不能再使用
    // println!("p after into_tuple = {:#?}", p);
}

这个例子和科学计算、模拟代码的思路相似：

状态数据：position, velocity, mass
只读计算：kinetic_energy, momentum, is_moving
原地更新：apply_force, step, stop
转换输出：into_tuple

今日总结

Day 6 的核心地图：

概念关键点
struct定义自己的数据类型
字段访问value.field
字段修改变量绑定需要 mut
#[derive(Debug)]自动生成调试打印能力
impl Type给类型定义方法和关联函数
&self只读借用当前对象
&mut self可变借用当前对象
self消耗当前对象
关联函数没有 self 参数，使用 Type::function() 调用
Self当前类型的别名
new常见构造函数模式，不是语言关键字
..old_valuestruct update syntax，可能复制或 move 字段

一句话总结：

Rust 用 struct 组织数据，用 impl 组织行为，并通过 &self / &mut self / self 明确表达方法如何使用所有权。
