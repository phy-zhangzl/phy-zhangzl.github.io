1. Iterator 的三条主线

Rust iterator 学习可以抓住三条主线：

1. 所有权：iter / iter_mut / into_iter
2. 惰性执行：map/filter 本身不运行，collect/sum/count 才触发
3. 类型流动：&T、&mut T、T、Option、Result 如何在链式调用中变化

如果这三条线清楚，Rust iterator 的大部分常见用法就能理解。

2. iter() / iter_mut() / into_iter()

核心口诀：

iter()      -> 借来看，产生 &T
iter_mut()  -> 借来改，产生 &mut T
into_iter() -> 拿走元素，产生 T

2.1 iter()：只读借用

fn main() {
    let nums = vec![1, 2, 3];

    for n in nums.iter() {
        println!("n = {n}");
    }

    println!("nums can still be used: {:?}", nums);
}

nums.iter() 不拿走 nums，而是产生一串 &i32。因此循环结束后，nums 仍然可以使用。

2.2 iter_mut()：可变借用

fn main() {
    let mut scores = vec![58, 76, 90];

    for score in scores.iter_mut() {
        *score += 5;
    }

    println!("curved scores = {:?}", scores);
}

iter_mut() 产生的是 &mut i32，所以需要用 *score 解引用后修改里面的值。

2.3 into_iter()：消费集合

fn main() {
    let words = vec![String::from("rust"), String::from("ai")];

    let upper: Vec<String> = words
        .into_iter()
        .map(|word| word.to_uppercase())
        .collect();

    println!("upper = {:?}", upper);

    // 取消注释会报错：words 已经被 into_iter() 消费。
    // println!("words = {:?}", words);
}

对于 Vec<String>，into_iter() 会把每个 String move 出来，因此原来的 words 不能再使用。

这和 Day 2 的所有权一致：String 不是 Copy，默认移动所有权。

3. Iterator 是 lazy 的

下面这段代码不会打印任何东西：

fn main() {
    let nums = vec![1, 2, 3];

    nums.iter().map(|x| {
        println!("{x}");
        x * 2
    });
}

原因是：

map 只是创建一个新的 iterator，不会立刻执行。

必须有 consumer 消费 iterator，代码才真正运行：

fn main() {
    let nums = vec![1, 2, 3];

    let doubled: Vec<i32> = nums
        .iter()
        .map(|x| {
            println!("mapping {x}");
            x * 2
        })
        .collect();

    println!("doubled = {:?}", doubled);
}

常见 adaptor：

map()
filter()
filter_map()
enumerate()
take()
skip()
zip()
chain()

常见 consumer：

collect()
sum()
count()
for_each()
any()
all()
find()
fold()

简单说：

adaptor 改造 iterator，consumer 真正消费 iterator。

4. Closure 语法

Closure 可以理解为匿名小函数：

#![allow(unused)]
fn main() {
|x| x + 1
}

类似 Python 中的：

lambda x: x + 1

Rust 中常见写法：

fn main() {
    let nums = vec![1, 2, 3];

    let doubled: Vec<i32> = nums.iter().map(|x| x * 2).collect();

    println!("doubled = {:?}", doubled);
}

这里：

#![allow(unused)]
fn main() {
|x| x * 2
}

表示对每个元素执行 x * 2。

Rust 的格式化宏还支持直接捕获变量名：

fn main() {
    let name = "Rust";
    let score = 95;

    println!("name = {name}");
    println!("score = {score}");
}

这和下面写法含义类似：

fn main() {
    let name = "Rust";
    let score = 95;

    println!("name = {}", name);
    println!("score = {}", score);
}

5. map / filter / collect

三个最常见的方法：

方法作用
map一对一转换
filter保留满足条件的元素
collect把 iterator 收集成集合

示例：

fn main() {
    let nums = vec![1, 2, 3, 4, 5];

    let doubled: Vec<i32> = nums.iter().map(|x| x * 2).collect();

    let evens: Vec<i32> = nums
        .iter()
        .filter(|x| **x % 2 == 0)
        .copied()
        .collect();

    println!("doubled = {:?}", doubled);
    println!("evens = {:?}", evens);
}

这里：

#![allow(unused)]
fn main() {
let doubled: Vec<i32> = ...collect();
}

需要写出 Vec<i32>，因为 collect() 可以收集成多种集合，Rust 需要知道目标类型。

也可以写成 turbofish 形式：

fn main() {
let nums = vec![1, 2, 3];
let doubled = nums.iter().map(|x| x * 2).collect::<Vec<i32>>();
println!("{:?}", doubled);
}

6. filter 中的引用层级

这是 Day 9 的重点之一。

fn main() {
    let nums = vec![1, 2, 3, 4];

    let evens: Vec<i32> = nums
        .iter()
        .filter(|x| **x % 2 == 0)
        .copied()
        .collect();

    println!("evens = {:?}", evens);
}

类型流动：

nums.iter()             -> Iterator<Item = &i32>
filter(|x| ...)         -> x 的类型是 &&i32
**x                     -> i32
filter 之后仍然是 &i32
copied()                -> &i32 变 i32
collect::<Vec<i32>>()   -> Vec<i32>

为什么 filter 里是 &&i32？

因为 filter 的 closure 收到的是“对 iterator item 的引用”。

而 nums.iter() 的 item 已经是：

&i32

所以 filter 里拿到：

&&i32

可以这样理解：

x   : &&i32
*x  : &i32
**x : i32

7. copied() 与 cloned()

copied() 用来把 &T 变成 T，前提是 T: Copy。

例如 i32 是 Copy：

fn main() {
    let nums = vec![1, 2, 3];

    let copied_nums: Vec<i32> = nums.iter().copied().collect();

    println!("copied_nums = {:?}", copied_nums);
    println!("nums = {:?}", nums);
}

String 不是 Copy，但它是 Clone，所以要用 cloned()：

fn main() {
    let words = vec![String::from("rust"), String::from("ai")];

    let cloned_words: Vec<String> = words.iter().cloned().collect();

    println!("cloned_words = {:?}", cloned_words);
    println!("words = {:?}", words);
}

区别：

copied() 用于 Copy 类型，例如 i32、f64、bool、char
cloned() 用于 Clone 类型，例如 String、Vec<T>

String 可以 clone，但不能 copy，因为它拥有堆内存，隐式按位复制会导致所有权问题。

8. filter_map：过滤 + 转换

filter_map 常用于“能转换就保留，不能转换就丢掉”的场景。

fn main() {
    let text = "10 20 bad 30";

    let nums: Vec<i32> = text
        .split_whitespace()
        .filter_map(|word| word.parse::<i32>().ok())
        .collect();

    println!("nums = {:?}", nums);
}

输出：

nums = [10, 20, 30]

流程：

"10"  -> Ok(10)  -> Some(10) -> 保留
"20"  -> Ok(20)  -> Some(20) -> 保留
"bad" -> Err(_)  -> None     -> 丢掉
"30"  -> Ok(30)  -> Some(30) -> 保留

其中：

#![allow(unused)]
fn main() {
.ok()
}

把：

Result<T, E> -> Option<T>

也就是：

Ok(value) -> Some(value)
Err(_)    -> None

所以：

#![allow(unused)]
fn main() {
filter_map(|word| word.parse::<i32>().ok())
}

表示：

能解析的数字留下，不能解析的跳过。

9. collect::<Result<Vec<_>, _>>()

如果不想跳过坏数据，而是遇到错误就返回 Err，可以使用：

fn parse_numbers(text: &str) -> Result<Vec<i32>, std::num::ParseIntError> {
    text.lines()
        .map(|line| line.trim())
        .filter(|line| !line.is_empty())
        .map(|line| line.parse::<i32>())
        .collect::<Result<Vec<_>, _>>()
}

fn main() {
    match parse_numbers("10\n20\n30\n") {
        Ok(nums) => println!("nums = {:?}", nums),
        Err(error) => println!("parse error: {error}"),
    }

    match parse_numbers("10\nbad\n30\n") {
        Ok(nums) => println!("nums = {:?}", nums),
        Err(error) => println!("parse error: {error}"),
    }
}

collect() 在这里可以把：

Iterator<Item = Result<i32, E>>

收集成：

Result<Vec<i32>, E>

含义：

全部成功 -> Ok(Vec<i32>)
有一个失败 -> Err(E)

所以：

#![allow(unused)]
fn main() {
.map(|line| line.parse::<i32>())
.collect::<Result<Vec<_>, _>>()
}

可以读作：

把每一行都解析成 i32；
如果全部成功，得到 Ok(Vec<i32>)；
如果某一行失败，整体返回 Err。

10. collect::<Result<Vec<_>, _>>()?

在返回 Result 的函数里，经常会看到：

#![allow(unused)]
fn main() {
fn parse_numbers(text: &str) -> Result<Vec<i32>, std::num::ParseIntError> {
    let nums: Vec<i32> = text
        .lines()
        .map(|line| line.trim())
        .filter(|line| !line.is_empty())
        .map(|line| line.parse::<i32>())
        .collect::<Result<Vec<_>, _>>()?;

    Ok(nums)
}
}

这句：

#![allow(unused)]
fn main() {
.collect::<Result<Vec<_>, _>>()?
}

分两步：

collect::<Result<Vec<_>, _>>()
    把 Iterator<Item = Result<T, E>> 变成 Result<Vec<T>, E>

?
    如果是 Ok(Vec<T>)，取出 Vec<T>
    如果是 Err(E)，从当前函数提前返回 Err(E)

所以它可以读作：

全部成功就拿到 Vec；遇到错误就提前返回。

和 filter_map(...ok()) 的区别：

写法错误处理方式返回类型
`filter_map(xx.parse().ok())`
`.map(xx.parse()).collect::<Result<Vec<_>, _>>()`

工程判断：

日志提取、弱清洗：坏 token 可以跳过 -> filter_map
配置文件、实验输入：坏一行就应该报错 -> collect Result

11. Closure 捕获外部变量

Closure 可以使用定义它时周围作用域里的变量。

fn main() {
    let threshold = 80;
    let scores = vec![95, 67, 88];

    let good: Vec<i32> = scores
        .iter()
        .copied()
        .filter(|score| *score >= threshold)
        .collect();

    println!("good = {:?}", good);
}

这里：

#![allow(unused)]
fn main() {
|score| *score >= threshold
}

使用了外部变量 threshold。

可以把 closure 想象成编译器生成的“带环境的小函数对象”。它不是单纯的函数指针，而是可以携带自己捕获的变量。

12. Fn / FnMut / FnOnce

Fn / FnMut / FnOnce 描述 closure 如何使用捕获的变量。

粗略对应：

Trait类比能调用几次典型行为
Fn&self多次只读使用外部变量
FnMut&mut self多次修改外部状态
FnOnceself至少一次可能拿走捕获的值

注意：

不是手动选择 Fn / FnMut / FnOnce，
而是编译器根据 closure 内部如何使用捕获变量自动判断。

12.1 Fn：只读捕获

fn call_fn<F>(f: F)
where
    F: Fn(),
{
    f();
    f();
}

fn main() {
    let threshold = 80;

    let show_threshold = || {
        println!("threshold = {threshold}");
    };

    call_fn(show_threshold);
    println!("threshold is still usable: {threshold}");
}

这个 closure 只是读取 threshold，可以调用多次。

12.2 FnMut：修改捕获变量

fn call_fn_mut<F>(mut f: F)
where
    F: FnMut(),
{
    f();
    f();
}

fn main() {
    let mut count = 0;

    let add_one = || {
        count += 1;
        println!("count = {count}");
    };

    call_fn_mut(add_one);
    println!("count after closure = {count}");
}

这个 closure 修改了外部变量 count，因此属于 FnMut。

12.3 FnOnce：消耗捕获变量

fn call_fn_once<F>(f: F)
where
    F: FnOnce(),
{
    f();
}

fn main() {
    let name = String::from("Rust");

    let consume_name = || {
        println!("dropping name = {name}");
        drop(name);
    };

    call_fn_once(consume_name);

    // 不能再次调用，因为 name 已经被消耗。
    // call_fn_once(consume_name);
}

这里 drop(name) 消耗了 name。String 不是 Copy，被 move 后不能再使用，所以这个 closure 只能调用一次。

13. move closure 不一定是 FnOnce

看到 move 不要立刻认为 closure 一定是 FnOnce。

fn call_fn<F>(f: F)
where
    F: Fn(),
{
    f();
    f();
}

fn main() {
    let language = String::from("Rust");

    let say_language = move || {
        println!("language = {language}");
    };

    call_fn(say_language);
}

这里使用了 move，表示 language 被移动进 closure 内部。

但是 closure 内部只是打印：

#![allow(unused)]
fn main() {
println!("language = {language}");
}

并没有消耗 language。因此这个 closure 仍然可以调用多次。

真正让 closure 变成只能调用一次的是：

fn main() {
let language = String::from("Rust");

let consume_language = move || {
    drop(language);
};

consume_language();
// consume_language(); // 不能再次调用
}

关键不是有没有 move，而是：

closure 内部是否消耗了捕获变量。

#[derive(Debug)]
struct Student {
    name: String,
    score: i32,
}

fn main() {
    println!("== 1. iter(): read values without moving the Vec ==");

    let nums = vec![1, 2, 3, 4, 5];

    for n in nums.iter() {
        println!("n = {n}");
    }

    println!("nums can still be used after iter(): {:?}", nums);

    println!("\n== 2. map/filter/collect on references ==");

    let doubled: Vec<i32> = nums.iter().map(|n| n * 2).collect();
    println!("doubled = {:?}", doubled);

    let evens: Vec<i32> = nums.iter().filter(|n| *n % 2 == 0).copied().collect();
    println!("evens = {:?}", evens);

    println!("\n== 3. iter_mut(): modify values in place ==");

    let mut scores = vec![58, 76, 90];

    for score in scores.iter_mut() {
        *score += 5;
    }

    println!("curved scores = {:?}", scores);

    println!("\n== 4. into_iter(): consume the Vec and own each String ==");

    let words = vec![
        String::from("rust"),
        String::from("ai"),
        String::from("infra"),
    ];

    let upper_words: Vec<String> = words.into_iter().map(|word| word.to_uppercase()).collect();
    println!("upper words = {:?}", upper_words);

    // Uncomment this line and run `cargo check`:
    // println!("words = {:?}", words);

    println!("\n== 5. closures can capture variables ==");

    let threshold = 80;
    let students = vec![
        Student {
            name: String::from("Alice"),
            score: 95,
        },
        Student {
            name: String::from("Bob"),
            score: 67,
        },
        Student {
            name: String::from("Carol"),
            score: 88,
        },
    ];

    let passed_names: Vec<&str> = students
        .iter()
        .filter(|student| student.score >= threshold)
        .map(|student| student.name.as_str())
        .collect();

    println!("passed names = {:?}", passed_names);
    println!("students can still be used after iter(): {:?}", students);

    println!("\n== 6. parse text with iterator chain ==");

    let text = "10\n20\n\nabc\n30\n";
    let numbers = parse_numbers_skip_bad(text);
    println!("numbers = {:?}", numbers);

    let total: i32 = numbers.iter().sum();
    println!("total = {total}");
}

fn parse_numbers_skip_bad(text: &str) -> Vec<i32> {
    text.lines()
        .map(|line| line.trim())
        .filter(|line| !line.is_empty())
        .filter_map(|line| line.parse::<i32>().ok())
        .collect()
}

use std::any::type_name;
use std::num::ParseIntError;

fn print_type_of<T>(name: &str, _: &T) {
    println!("{name}: {}", type_name::<T>());
}

fn print_type_of_value<T>(name: &str, _: T) {
    println!("{name}: {}", type_name::<T>());
}

fn call_fn<F>(f: F)
where
    F: Fn(),
{
    println!("call_fn: first call");
    f();
    println!("call_fn: second call");
    f();
}

fn call_fn_mut<F>(mut f: F)
where
    F: FnMut(),
{
    println!("call_fn_mut: first call");
    f();
    println!("call_fn_mut: second call");
    f();
}

fn call_fn_once<F>(f: F)
where
    F: FnOnce(),
{
    println!("call_fn_once: only call");
    f();
}

fn parse_numbers_strict(text: &str) -> Result<Vec<i32>, ParseIntError> {
    text.lines()
        .map(|line| line.trim())
        .filter(|line| !line.is_empty())
        .map(|line| line.parse::<i32>())
        .collect::<Result<Vec<_>, _>>()
}

fn parse_numbers_strict_with_question_mark(text: &str) -> Result<Vec<i32>, ParseIntError> {
    let nums: Vec<i32> = text
        .lines()
        .map(|line| line.trim())
        .filter(|line| !line.is_empty())
        .map(|line| line.parse::<i32>())
        .collect::<Result<Vec<_>, _>>()?;

    Ok(nums)
}

fn experiment_1_references_copied_cloned() {
    println!("== Experiment 1: references, copied(), cloned() ==");

    let nums = vec![1, 2, 3, 4, 5, 6];

    println!("\n-- iter() gives references --");
    let first = nums.iter().next().unwrap();
    print_type_of("first from nums.iter()", &first);
    println!("first = {first}");

    println!("\n-- filter() receives a reference to each iterator item --");
    let even_refs: Vec<&i32> = nums
        .iter()
        .filter(|x| {
            print_type_of_value("x inside filter", x);
            **x % 2 == 0
        })
        .collect();

    print_type_of("even_refs", &even_refs);
    println!("even_refs = {:?}", even_refs);

    println!("\n-- copied() changes &i32 into i32 --");
    let evens: Vec<i32> = nums.iter().filter(|x| **x % 2 == 0).copied().collect();

    print_type_of("evens", &evens);
    println!("evens = {:?}", evens);
    println!("nums is still usable after iter(): {:?}", nums);

    println!("\n-- cloned() changes &String into String --");
    let words = vec![
        String::from("rust"),
        String::from("ai"),
        String::from("infra"),
        String::from("tool"),
    ];

    let short_word_refs: Vec<&String> = words.iter().filter(|word| word.len() <= 4).collect();
    let short_words: Vec<String> = words
        .iter()
        .filter(|word| word.len() <= 4)
        .cloned()
        .collect();

    print_type_of("short_word_refs", &short_word_refs);
    println!("short_word_refs = {:?}", short_word_refs);

    print_type_of("short_words", &short_words);
    println!("short_words = {:?}", short_words);
    println!("words is still usable after iter() + cloned(): {:?}", words);

    // Try changing cloned() to copied() above. String is Clone, but not Copy.
}

fn experiment_2_filter_map_vs_collect_result() {
    println!("\n== Experiment 2: filter_map vs collect::<Result<Vec<_>, _>>() ==");

    let text = "10\n20\n\nbad\n30\n";

    println!("\n-- filter_map + ok(): skip bad values --");
    let nums_skip_bad: Vec<i32> = text
        .lines()
        .map(|line| line.trim())
        .filter(|line| !line.is_empty())
        .filter_map(|line| line.parse::<i32>().ok())
        .collect();

    println!("nums_skip_bad = {:?}", nums_skip_bad);

    println!("\n-- collect Result: fail on the first bad value --");
    let nums_strict: Result<Vec<i32>, ParseIntError> = text
        .lines()
        .map(|line| line.trim())
        .filter(|line| !line.is_empty())
        .map(|line| line.parse::<i32>())
        .collect();

    println!("nums_strict = {:?}", nums_strict);

    println!("\n-- same strict idea inside a function --");
    match parse_numbers_strict(text) {
        Ok(nums) => println!("strict parsed nums = {:?}", nums),
        Err(error) => println!("strict parse failed: {error}"),
    }

    println!("\n-- strict parse with ? --");
    match parse_numbers_strict_with_question_mark("10\n20\n30\n") {
        Ok(nums) => println!("all good nums = {:?}", nums),
        Err(error) => println!("parse failed: {error}"),
    }

    match parse_numbers_strict_with_question_mark(text) {
        Ok(nums) => println!("all good nums = {:?}", nums),
        Err(error) => println!("parse failed and returned early: {error}"),
    }
}

fn experiment_3_fn_fnmut_fnonce() {
    println!("\n== Experiment 3: Fn, FnMut, FnOnce ==");

    println!("\n-- Fn: only reads captured variables, can be called many times --");
    let threshold = 80;
    let is_good = || {
        println!("threshold = {threshold}");
    };

    call_fn(is_good);
    println!("threshold is still usable: {threshold}");

    println!("\n-- FnMut: mutates captured state, can be called many times if mutable --");
    let mut count = 0;
    let add_one = || {
        count += 1;
        println!("count inside closure = {count}");
    };

    call_fn_mut(add_one);
    println!("count after call_fn_mut = {count}");

    println!("\n-- FnOnce: consumes captured value, can only be called once --");
    let name = String::from("Rust");
    let consume_name = || {
        println!("dropping name = {name}");
        drop(name);
    };

    call_fn_once(consume_name);
    // Uncommenting the next line will not compile because consume_name was moved into call_fn_once.
    // call_fn_once(consume_name);

    println!("\n-- move closure does not always mean FnOnce --");
    let language = String::from("Rust");
    let say_language = move || {
        println!("language = {language}");
    };

    call_fn(say_language);

    println!("\nKey idea:");
    println!("Fn     = reads captured values, like &self");
    println!("FnMut  = mutates captured values, like &mut self");
    println!("FnOnce = may consume captured values, like self");
}

今日总结

Day 9 的核心地图：

概念关键点
iter()只读借用，产生 &T
iter_mut()可变借用，产生 &mut T
into_iter()消费集合，产生 T
lazy iteratormap / filter 等不立刻执行
consumercollect / sum / count 等触发执行
map一对一转换
filter保留满足条件的元素
collect收集成目标集合，常需要类型提示
copied()&T -> T，要求 T: Copy
cloned()&T -> T，要求 T: Clone
filter_map过滤和转换合并，常配合 ok() 跳过错误
collect::<Result<Vec<_>, _>>()全部成功得到 Ok(Vec<_>)，遇错得到 Err
closure匿名小函数，可以捕获外部变量
Fn只读捕获变量，可多次调用
FnMut修改捕获变量，可多次调用但需要可变调用
FnOnce可能消耗捕获变量，只保证能调用一次

一句话总结：

Iterator 是 Rust 中表达数据流的核心工具；closure 决定每一步如何转换、过滤或消费数据。
